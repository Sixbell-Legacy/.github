# Modelo de ownership

## Roles

### Organization Owners

Responsables de configuración administrativa de Sixbell-Legacy. Deben ser pocos y existir al menos dos personas para evitar dependencia de una sola cuenta.

### Legacy Maintainers

Mantienen únicamente repositorios clasificados como `LEGACY-SUPPORTED` donde exista una necesidad operacional real.

### Engineering

Acceso de lectura por defecto. La escritura se concede únicamente cuando existe una necesidad justificada.

### SAC / Operaciones

Acceso según necesidad operacional y repositorios bajo soporte.

### Seguridad / COP

Acceso necesario para revisión de seguridad, auditoría y cumplimiento.

## Principio de mínimo privilegio

La pertenencia a Sixbell-Legacy no implica permiso de escritura sobre todos sus repositorios.

Los permisos específicos del repositorio prevalecen para los casos que requieren acceso adicional.
